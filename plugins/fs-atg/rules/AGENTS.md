# France Student [ATG]

PRIORITÉ ABSOLUE — Mode Automatique actif (permission : `full`) : pour **toute création de fichier, modification, refactorisation, débogage, exploration de code, planification, exécution de tests/commandes ou analyse technique**, appelle **IMMÉDIATEMENT EN PREMIER** `fs_delegate` avec `workspaceRoot` (chemin absolu du projet), `contextMode="minimal"` et `waitSeconds=120`. **INTERDICTION** de lire les fichiers (`read_file`, `grep_search`, `find_by_name`) ou de les éditer (`edit_file`, `write_file`) en natif avant d’appeler `fs_delegate` : France Student dispose de ses propres outils locaux (`list_directory`, `search_files`, `read_file`, `edit_file`, `write_file`, `run_command`) avec sauvegarde atomique `/undo`, agit directement sur le disque et te renvoie un bilan court (`filesWritten`, `commandsRun`).

- **Agent principal natif** : l’agent `france-student` (`agents/france-student.md`) applique ce workflow ; sélectionne-le dans Antigravity App (agent principal) ou via `/agents` dans Antigravity CLI.
- **Routage intelligent par spécialité (y compris en MAX) & Économie Opus** : adapte toujours le modèle à la complexité et à la spécialité, **jamais Opus H24** :
  - **Recherche / exploration simple, Q/R, résumé, traduction, typo, petite doc** → léger (`gpt-6-luna` / `claude-haiku-5-5`, `routingProfile="eco"`, `reasoningEffort="standard"` ; ou `invoke_subagent` avec `Model="flash_lite"`/`"flash"`).
  - **Backend, scripts, SQL, data, tests, debug standard** → équilibré OpenAI (`gpt-6.2-sol`, `routingProfile="auto"`, `reasoningEffort="deep"`).
  - **UI, CSS, Svelte/React, Canvas, rédaction soignée** → équilibré Anthropic (`claude-sonnet-5-5`, `routingProfile="auto"`, `reasoningEffort="deep"`).
  - **Vision Live / Computer Use** → `gpt-6.1-terra`.
  - **Algorithmes complexes, concurrence, maths** → fort OpenAI (`gpt-6.2-astra`, `reasoningEffort="max"`).
  - **Architecture multi-fichiers lourde / sécurité critique** → fort Anthropic (`claude-opus-5-5`, réservé aux vrais gros chantiers et évité sous 30 % de budget sauf `/opus`).
- **Commandes slash officielles** (Mode Automatique et Mode Manuel) : `/fs` (déléguer, écriture directe `workspaceRoot` + `/undo`), `/max` (`reasoningEffort="max"` + priorité Fort sur tâches complexes), `/patch` (patch ciblé), `/plan` (plan en lecture seule), `/eco` (profil Éco), `/undo` → `fs_undo`, `/remember` → `fs_memory`, `/quota` → `fs_quota` + `fs_diagnostics`, `/canvas` → `fs_canvas`, `/computer` → `fs_computer`, `/think` → `fs_thinking`.
- **Budget 0 % strict** : à 0 % (ou sous la réserve), France Student route uniquement vers les modèles hors-quota Mistral, sans recherche ni repli vers un modèle à quota ; ne force pas d’autre modèle via `model`. Si aucun modèle hors-quota n’est autorisé, informe l’utilisateur au lieu de réessayer.
- **Cooldown `IA non dispo`** : ne rappelle pas `fs_delegate` en boucle ; exécute en natif Antigravity pendant le cooldown (≈ 10 min) en le signalant (et utilise `Model="flash"`/`"flash_lite"` sur `invoke_subagent` pour les tâches simples), puis reviens à `fs_delegate`.
- **Zéro gaspillage de quota Antigravity** : ne fais jamais d’exploration ou de réécriture native quand `fs_delegate` peut tout exécuter de bout en bout sur disque avec `workspaceRoot`. Une fois `fs_delegate` terminé (`status: "done"` avec `filesWritten`), présente directement le résultat à l’utilisateur sans relire ni rééditer les fichiers modifiés. Si besoin d’annuler : `/undo` → `fs_undo`.
- **Exceptions natives strictes** : garde en natif Antigravity **uniquement** : (1) réponse ultra-courte de confirmation/clarification (`<= 2` lignes), (2) micro-retouche triviale `< 5 lignes` déjà entièrement visible dans le message, (3) recherche web externe (`search_web`) ou navigateur (`browser`).
- **Raisonnement boosté & Mémoire** : utilise `reasoningEffort="max"` (ou `/max`) sur les tâches complexes ; `/remember` appelle `fs_memory` (`FRST.md` + notes + faits appris sont injectés automatiquement au 1er tour).
- **Contrôle par modèle (Oui / À demander / Non)** : si `fs_delegate` renvoie `status: "needs_approval"`, demande explicitement l’accord de l’utilisateur avant d’utiliser le modèle recommandé (ou propose une alternative autorisée), puis relance `fs_delegate` avec `approveModel="<modelId>"` (ou `model="<alternative>"`). N’utilise jamais un modèle réglé sur « Non ».
- **Cascade 502/429 & Cooldown 10 min (`IA non dispo`)** : en cas d’erreur 502/503/429, France Student bascule automatiquement du meilleur modèle au moins fort (`heavy` → `medium` → `light`). Si aucun modèle ne répond, un cooldown de 10 min est activé avec le motif `IA non dispo` : pendant ce cooldown, exécute directement la tâche en natif sans rappeler `fs_delegate`.
- **Mistral hors quota** : les modèles Mistral (`ministral*`) passent outre les quotas France Student (utilisables sans limite même à 0 % de budget restant ou sous la réserve, sauf s’ils sont réglés sur « Non »).
- **Plan B** : si Plan A échoue hors `IA non dispo`, relance en `planB: true` avec `parts` (2–4 petits blocs) ; n’exécute nativement qu’en tout dernier recours.
- **Quota & état** : `/quota` → `fs_quota` (quota, cooldown `IA non dispo`) puis `fs_diagnostics` (connexion, modèles) ; `fs_logs` et `fs_session` restent disponibles comme outils. `/usage` mesure Antigravity.
- **Computer Use (bureau Windows, `/computer`)** : `fs_computer` pilote le vrai bureau (souris, clavier, fenêtres, presse-papiers) et expose Windows UI Automation (`action="ui_tree"` en lecture seule pour lister boutons/champs avec coordonnées exactes, `action="ui_click"` par `name`/`automationId`). Commence par `action="screen_info"` ou `action="ui_tree"`, puis `action="screenshot"` avec `screenIndex` (0 = 1er écran, défaut 0) ou `deviceName`. Les actions qui modifient le bureau sont bloquées en mode `plan`.
- **Outils locaux zéro-dépendance** : `fs_fetch` (lecture web Markdown protégée SSRF), `fs_doc_read` (Markdown/Texte/CSV/HTML, `.docx`/`.pptx`/`.xlsx` natifs Windows et PDF si extracteur présent), `fs_git` (inspection Git lecture seule : `status`, `diff`, `log`, `branch`, `show`) et `fs_media` (images natives Windows, export SVG→PNG, vidéo FFmpeg et rendu HTML→MP4 HyperFrames).
- **Boucle Vision Live** : pour une tâche visuelle, appelle `fs_delegate` avec `attachScreenshot: true` (+ `screenIndex`) ou `imagePaths`, et `liveComputerMode: true`. France Student voit la capture et répond par UNE action `fs_computer` à exécuter ; exécute-la, puis relance `fs_delegate` avec une nouvelle capture. Répète jusqu’à ce que la tâche soit finie (max ~10 tours), et arrête-toi au moindre doute (paiement, suppression, envoi de message).
